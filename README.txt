INSPIRATIONS OF THE UNIVERSE

**By Arinde Maurice**

Creator portrait: images/arinde-maurice.jpg

A personal astronomy + computer science portfolio project combining interactive astronomy tools, research, scientific visualization, NASA imagery and web development.

## What this project includes
- Interactive Solar System research page
- Real planet imagery with source attribution
- Night Sky Dashboard with Astronomy Engine
- NASA Image & Video Library search
- NASA Astronomy Picture of the Day
- NASA Research Vault and evidence cards
- Personal research notebook saved in the browser
- Cosmic Motion Lab
- Responsive visual design
- Creator portfolio section for Arinde Maurice

## Run locally
1. Open this folder in VS Code.
2. Start it with **Live Server**.
3. Open `index.html`.

## Image sources
Real planet imagery in the website is linked to NASA/JPL material and Wikimedia Commons copies/collections where appropriate. The individual planet cards include source links. NASA source pages include Mercury, Venus, Jupiter, Saturn, Uranus and Neptune material.

## Important
NASA/JPL/ESA imagery and data remain attributed to their published sources. This is an independent educational portfolio project and does not imply NASA endorsement.
